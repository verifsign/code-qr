# Images sources MHC

Déposez ici l’archive `mhc-images.zip` (20 PNG) avant de lancer l’agent.

```bash
# Depuis votre Mac, après clone du repo :
cp ~/Downloads/mhc-images.zip mhcmedical/_sources/
git add mhcmedical/_sources/mhc-images.zip
git commit -m "Ajout archive images MHC"
git push
```

Puis demandez à l’agent : *« Traite les images dans `mhcmedical/_sources/mhc-images.zip` »*.
